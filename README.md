# POKEMON-DATA

This project focuses on exploring and analyzing the Pokémon dataset using Python.

The goal is to perform data analysis and create visualizations to better understand Pokémon attributes, distributions, and relationships between different features.

The project demonstrates data cleaning, exploratory data analysis (EDA), and advanced visualization techniques.

Tech stack: Python, Pandas, NumPy, Matplotlib, Seaborn

Key steps:

Data loading and preprocessing
Exploratory data analysis (EDA)
Feature distribution analysis
Statistical summaries of Pokémon attributes
Data visualization (plots, charts, comparisons)
